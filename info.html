¿Qué es el Vibe coding?, Cómo funciona y qué beneficios ofrece

“Solo fluye con la IA. Introduce el prompt, obtén el código, ejecútalo, comprueba qué falla, inténtalo de nuevo, edita un poco, pégalo, repite. No necesitas nada más. Los límites están en tu cabeza. Tú solo crea.”

A ese bucle se le llama “Vibe Coding”, introducido por el renombrado científico informático Andrej Karpathy en febrero de 2025. Según Andrej, se trata de una estrategia de codificación que requiere una mínima intervención humana, básicamente, en el uso de herramientas de inteligencia artificial para crear código en vez de que lo escriba una persona.

Lo que lo diferencia del uso habitual de inteligencias generativas para código es el contexto y la continuidad. En el vibe coding, trabajas en un entorno donde la IA tiene acceso a toda la base de código del proyecto, puede modificar varios archivos a la vez, ejecutar el código para ver si funciona y corregir los errores automáticamente. No es un intercambio de preguntas y respuestas — es un colaborador que vive dentro de tu proyecto.

Como Funciona

Un flujo típico de vibe coding para alguien sin experiencia en programación tiene cuatro pasos que se repiten en ciclo:

  1. Describir el objetivo.

    No el código — el resultado. "Quiero una tabla que muestre mis clientes con nombre, email y fecha de última compra, con un botón para añadir uno nuevo." Cuanto más específica es la descripción, mejor el resultado.

  2. Generar y revisar.

    La IA genera el código y, en herramientas como Bolt o Lovable, muestra el resultado visual en tiempo real. No necesitas leer el código — necesitas evaluar si lo que ves hace lo que querías.

  3. Iterar con lenguaje natural.

    Lo que no está bien se corrige con más descripción: "El botón está muy grande", "Quiero que la tabla se ordene por fecha", "Falta un campo para el teléfono". Cada ajuste es un prompt, no una línea de código.

  4. Corregir errores cuando aparecen. Aquí está la parte que menos se explica. Cuando algo falla — y fallará — el flujo ideal es copiar el mensaje de error y pegárselo a la IA con una instrucción simple: "Esto da error, corrígelo". La mayoría de veces lo resuelve solo. Cuando no lo resuelve, es el momento en que tener algo de criterio técnico marca la diferencia.
